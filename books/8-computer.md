# 💻 Computer

## Overview
This book covers computer science, programming, technology, and digital skills.

---

## 🧠 Important Flash Cards

**Q1. What is a computer?**  
**A:** A computer is an electronic machine that processes information.

**Q2. What is programming?**  
**A:** Programming means giving instructions to a computer.

**Q3. What is technology?**  
**A:** Technology is the use of knowledge and tools to solve problems and do work.

**Q4. What are digital skills?**  
**A:** Digital skills are skills used to work safely and effectively with digital devices and information.

**Q5. What is hardware?**  
**A:** Hardware is the physical part of a computer that we can touch.

**Q6. What is software?**  
**A:** Software is a set of programs that tells a computer what to do.

**Q7. What is a keyboard?**  
**A:** A keyboard is an input device used to type letters, numbers, and commands.

**Q8. What is a mouse?**  
**A:** A mouse is a pointing device used to select and control items on a screen.

**Q9. What is a monitor?**  
**A:** A monitor is an output device that displays information.

**Q10. What is the CPU?**  
**A:** CPU stands for Central Processing Unit. It processes instructions in a computer.

**Q11. What is the internet?**  
**A:** The internet is a worldwide network that connects computers and devices.

**Q12. What is a file?**  
**A:** A file is a collection of digital information stored with a name.

**Q13. What is a folder?**  
**A:** A folder is used to organize files on a computer.

**Q14. What is a password?**  
**A:** A password is secret information used to help protect an account or device.

**Q15. What is digital safety?**  
**A:** Digital safety means using devices and the internet carefully and protecting personal information.

### 🖥️ Basic Computer Parts
- Keyboard — typing
- Mouse — pointing and selecting
- Monitor — showing information
- CPU — processing instructions
- Printer — printing information on paper
